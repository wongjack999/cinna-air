# Cinna Air — 整合版 V6

以瀏覽器開啟 [index.html](index.html) 可以離線試玩。

1. **邀請函與機場報到**。開信後向上拖入機場，左右翻閱三頁航班，再揀 NAT818（ICN，A2）。玉桂狗出場後，拖護照到櫃檯、填寫遊戲內嘅入境資料卡並簽名，再向下拉出登機證。領證後解鎖 HK$600 基本購物金，點按「進入飛機」前往機艙。
2. **機艙挑戰**。點按飛機窗開始，30 秒內點按窗外星星同蝴蝶結。完成後向上滑動去行李帶。基本技巧獎金 HK$100，每收集一個目標加 HK$20，上限 HK$300。
3. **幸運行李箱**。三選一揭曉 HK$100–500 幸運獎金。Princess Shopping Pass 原地顯示三項獎金同總額，結果保留喺目前瀏覽器分頁。結果畫面向上滑動即可重玩。

[旅程元件庫](components.html) 提供素材同玻璃 UI 預覽。整合方法見 [COMPONENTS.md](COMPONENTS.md)。

遊戲使用本機圖片及同一頁場景切換。簽名只用於本次報到，確認後會清除。
